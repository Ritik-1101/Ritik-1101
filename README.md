### 🚀 What I Do

I blend an attacker's mindset with a defender's mission. Whether it's hunting for hidden threats or writing scripts to automate the boring stuff, I love diving deep into systems.

- 🔍 **Penetration Testing:** Exploiting vulnerabilities across web apps, networks, and Active Directory environments.
- 🛡️ **Security Operations (SOC):** Analyzing threats, automating incident response workflows, and hunting for APTs.
- 💻 **Offensive Tooling:** Writing custom Python and Bash scripts for post-exploitation and automated network recon.
